# 小诺产品剩余工作清单（2026-08-23 结转）

> 本文记录 0.2.84 发布后仍未完成的产品计划项，按优先级排列。
> 活动勾选清单见 `docs/knoa-product-todo.md`；本文是按工作量组织的推进视图。
> 方针：正向设计、高内聚低耦合、YAGNI；每项独立设计、独立提交。

## 大项（需要独立设计周期）

### 1. App 关闭后的系统级远程推送（P1.2 核心）

- 现状：通知为 App 在线事件流 + expo-notifications 本地通知；文案已如实标注「App 运行期间送达」，设置页有测试通知。
- 缺口：App 完全关闭、进程被杀后，任务完成/失败/审批无法到达手机。
- 方向：Core 持久化 Notification Intent（完成、失败、审批、补充信息、Node 离线、需要更新）作为唯一事实源；接入 FCM/APNs 级远程推送；App、飞书、钉钉、桌面复用同一事实，支持去重、深链、测试和过期。
- 关键决策：推送服务归属（Hub 直推 or 第三方推送网关）、密钥管理、通知与事件游标的一致性。

### 2. 浏览器能力产品化（P1.6）

- 现状：有 web_search/web_fetch 工具和桌面鼠标键盘控制。
- 缺口：浏览器启动、导航、页面读取、点击/输入、下载跟踪和持久会话没有产品化入口；在实现前不得向用户暗示系统能稳定处理网页工作。
- 方向：Node 侧浏览器会话管理 + App 侧无入口暴露细节的结果交付；先做单页导航/读取/下载三个可验收动作，再扩展持久会话。

### 3. 扩展一键安装能力（P1.4）

- 现状：Skill/MCP 支持本地/远程导入和 inspect/draft/publish。
- 缺口：用户仍需理解 server id、内部路径；没有预检权限、启用/停用、更新和回滚的一键流程。
- 方向：能力包格式（清单 + 权限声明 + 预检脚本）、导入即预检、失败可回滚，默认不要求填写内部对象。

### 4. Webhook/MCP Resource 用户流程（P1.5 残留）

- 现状：TaskLaunchEditor 可选 MCP Resource；后端 Trigger 存在。
- 缺口：创建、复制地址、生成密钥、测试触发、暂停和查看最近事件的用户流程。

### 5. 自我进化闭环（P2）

- 现状：有评测和候选设计。
- 缺口：用户反馈/失败证据 → 失败分类 → 评测集 → 候选 → 沙箱回放 → 人工批准 → 灰度 → 监控 → 回滚的完整控制面。
- 边界（已有设计约束）：允许自动化的范围不含权限上限、审批策略、凭据、隔离边界和安全等级。

### 6. 能力包市场与版本治理（P2）

- 依赖：第 3 项的一键安装先落地；不引入通用 Workflow DSL 或企业治理中心。

## 中项（单次提交可完成）

1. **握手阶段细分打点**：连接诊断已有每请求承载链路与总耗时；补 DNS/TCP/TLS、mDNS 发现、P2P ICE、Relay 握手各阶段耗时（`gatewayTransport.ts` + 设置页连接质量）。
2. **scheduled/event 触发路径预检时机**：创建即执行已走预检（`gateway/routes/tasks.py` 两步流程）；定时/事件触发前的预检与失败通知策略未定。
3. **任务创建文件夹级输入**：文件/图片附件已有；文件夹选择（递归枚举、数量上限）未做。
4. **Chat 失败后编辑重发、回到最新**：停止、重试、附件逐项状态已有。
5. **执行详情页统一摘要组件**：结果中心已结构化（完成/未完成/证据/下一步）；执行详情页复用同一组件并补修改清单与一键继续。
6. **Console 一键修复**：三类状态总览已有；每个问题的一键修复、重查和日志查看待接。
7. **Console 版本信息补全**：安装/运行版本已有；补源码 commit 与配置 revision 显示。
8. **链路切换历史**：当前链路与每链路请求耗时已有；切换历史待补。

## 已知问题（不阻塞发布，需专项处理）

1. **`test_restart_pauses_interrupted_task_until_explicit_resume` 竞态 flaky**：仓库状态置 RUNNING 与 runtime 请求记录之间存在窗口，stop() 落在窗口内时 `first_runtime.requests` 为空导致 IndexError。修复需先厘清 stop-while-held 的取消语义；直接加强轮询条件会引入挂起风险（已试并回退）。
2. **本机 Windows 环境既有测试失败约 77 项**：POSIX 路径、进程组、chmod 权限、子进程 GBK 解码类，与产品代码无关；Linux CI 上应为绿色。
