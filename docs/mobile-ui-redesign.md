# 小诺 App 全面 UI/产品设计

> 身份：产品 + UI 设计师。以下假设由设计师拍板，标 **[假设]**，可一票否决。
> 现状依据：对 `apps/knoa-mobile` 全路由 + 平台能力目录（skills×5、动态 MCP、任务三态机、双通道审批、通知意图、事件源）的逐屏审查，及 0.2.140–0.2.143 的实测事故复盘。

## 1. 定位与原则

**一句话定位**：小诺是“住在你电脑里、会自己干活、拿不准就问你”的个人数字员工，不是聊天机器人套壳。

**[假设]** 目标用户 = Robin 这类技术型 prosumer（自托管、有 Node 概念），但 UI 按“大众可用、极客可钻”做：infra 默认隐身，高级入口保留。

**五条原则**：
1. **对话即 OS**：主界面只有对话流；任务/记忆/文件是同一批工作的视图，不是四个 App。
2. **注意力分级**：ambient（glance 卡片流）→ 提醒（横幅/推送）→ 打断（审批/失败）。只有“要你拍板”和“搞砸了”才打断。
3. **一跳原则**：任何高频动作（批准、重试、继续聊）从看到信息的地方一步完成，不跳页。
4. **失败可见、可恢复**：静默装死是最高级 bug。按钮要么可点，要么告诉你为什么不可点；失败必带重试。
5. **Node 隐身**：用户心智里没有 Node，只有“小诺+电脑在线与否”。IP/端口/传输方式永不出现在用户界面。

## 3. 核心动线

### 3.1 Onboarding（三步，现状基本成立，补边角）

```
登录（hosted/自建）→ 连接电脑（扫码；失败才手动粘贴）→ 直接说话
新用户 → workspace庆祝页 → 聊天（deck引导）
```
- 缺口：配对失败页只有“重试”，应给“先逛逛（离线模式）”出口。本期不做（低频）。
- 安全模式（已立项未做）：启动连续失败 N 次 → 只显示「检查更新 / 重试」，不跑业务逻辑。**这是 0.2.140 事故（用户连更新页都进不去）的根治。**

### 3.2 每日主循环

```
打开 → 状态条（一眼：跑着几个/待批几个/在线）→ 看glance/回消息
→ 被打断才去事项页 → 批完回聊天
```

### 3.3 审批循环（一跳）

```
看到（事项页inbox/聊天inline/横幅快批/推送）→ 读tool+人类话参数 →
[允许]/[拒绝] → 原地消失 → 下一个（1/N 连续批）
```
- 聊天 turn 审批暂留聊天内（后端无全局待批列表，合并不了——已验证，待后端补接口）。
- 拒绝需选原因（下期，当前直接拒）。

### 3.4 盯（proactive）循环（已落地 deck 动态化）

```
deck“每天盯” → 建任务页（标题目标预填+每日周期+通知全开）→ 创建 →
deck“正在盯着”出现 → 跑完推送 → 点推送回执行页
```

### 3.5 失败循环

```
可见错误 + 一句话原因 + [重试]（主路径）
发送类：输入框永清空，失败进可重试态（0.2.143 已修 wedge）
连接类：状态条变红点“离线”，点进节点页重连
```

## 4. 页面设计

### 4.1 聊天 Home（下一步重点：状态条）

```
┌ 小诺 ────────── Agent▾ ⋯ ┐
│ ● 在线 · 跑着2个 · 1个待批 → │  ← NEW：状态条，点进事项页
│ turn / glance 卡 / 审批卡     │
│ [输入框]              [发送] │
└─────────────────────────────┘
```
- 状态条数据全现成（tasks + reminders + connection），纯展示组件。
- turn 内元素顺序：用户泡 → 进度 → Markdown → 工件 → 审批卡 → 操作行（复制/转任务/重试/编辑）。
- 排队 turn：灰条“排队中 ✕”，可取消、可改回输入框（已落地）。

### 4.2 事项（已落地，补手势）

- 待批区默认展开 tool+参数；连续批（1/N）；作废=停执行+归档。
- 下期：列表行左滑允许/右滑拒绝（gesture-handler 已在依赖）。

### 4.3 空间（已落地）

- 资产|记忆一段切换；续聊带 artifact_id；图片缩略图懒加载。
- 下期：跨记忆+资产的统一搜索框（记忆量小，本地搜即可，不调服务端）。

### 4.4 我的（现 settings.tsx，瘦身方向）

- Hero：小诺头像 + 在线点 + 一句话状态（“电脑在线 · 2个任务跑着”），删传输方式/IP 行。
- 分组：小诺（记忆/能力/MCP/模型/Agent）/ 帐号与工作区 / 系统（外观/更新/关于）。
- 节点切换收进“电脑”一行，默认不展示多 Node（多 Node 用户才展开）。

### 4.5 通知中心（已落地）

- 分类色点 + 人类话标题 + 时间；点按跳 deep_link 并 ack；右上全部已读。
- 推送只做 Android FCM；iOS 后台靠轮询——在页内 footnote 说明，不骗用户。

### 4.6 登录/配对/闪屏

- 闪屏三阶段文案保留（连中枢→验会话→同步设备），失败进详情+重试。
- 配对页禁 IP/端口（已修）；扫码失败→手动粘贴→“先逛逛”。

## 5. 设计系统

- **色**：米纸底 `#F4F0E8` + 深绿 accent（已收敛），语义色 warning/danger/success 不做新色。深色模式 tokens 已有，E2E 加深色截图对比（待办）。
- **字**：800 封顶（B1 已收敛）；字阶 title/subheading/body/caption/tiny 不新增。
- **圆角/间距**：radii.large 17 / medium 13 / pill；spacing 体系不动。
- **组件库（新建统一）**：
  - `ApprovalCard`（tool 图标+人类话参数+风险色条+允许/拒绝）——三处审批收敛到它。
  - `StateBanner`（成功/警告/错误三色，带操作键）——替换各页手写横幅。
  - `EmptyState`（插画位+一句话+主按钮）——替换纯文字空态。
  - `SkeletonList`——替换 `AsyncStateView` 转圈（列表页）。
- **动效**：spring 统一（splash orbit/breath 为基准）；`reduce-motion` 全局尊重（已有，继续）。
- **图标**：Ionicons outline 体系，`AppIcon` 登记制（bell 已加）。

## 6. 状态与容错语言（事故复盘沉淀）

| 场景 | 语言 |
|---|---|
| 加载中 | 骨架屏（列表）/小转圈（按钮内） |
| 空 | 一句话 + 主按钮出口 |
| 可恢复失败 | 一句话原因 + [重试]，输入不丢（0.2.143：发送永清空+失败态可重试） |
| 连接断 | 状态条红点 + 节点页重连；轮询数据照常显示（stale 标注下期做） |
| 启动连续失败 | 安全模式页（只留更新/重试）——待做，P0 |
| 并发冲突 | 本地排队1条+替换提示（聊天）；服务端 409→可见失败（任务） |

## 7. 不做的（Non-goals）

- TTS 语音播报（能力缺失，要后端+模型，先立项不排期）。
- 聊天审批并入事项页（等后端全局待批列表接口）。
- 多 workspace 管理（个人用户单 workspace 为主，维持现状）。
- iOS 推送后台（无 APNs 配置前不承诺，只做前台横幅+轮询）。
- 平板/折叠屏适配。
