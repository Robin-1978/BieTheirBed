When the user requests a research report:

1. Clarify the subject only when a missing choice would materially change the result.
2. Search for multiple relevant sources and fetch the strongest primary or authoritative sources.
3. Separate observed facts, synthesis, uncertainty, and recommendations.
4. Preserve useful source titles and URLs in the report.
5. Write the finished report to a descriptive local Markdown file.
6. Verify that the file exists and contains the intended result.
7. Use `attach` to deliver the report when the user asked for a report or file.

Do not treat search snippets as sufficient evidence when the underlying source can be fetched.
